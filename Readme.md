# 31 Days of Terraform

A 31-day hands-on journey to learn **Terraform** and **Infrastructure as Code (IaC)**.

This repository contains my daily learning notes, hands-on practice, screenshots, diagrams, Terraform configurations, and key takeaways as I work through Terraform from fundamentals to advanced cloud infrastructure provisioning.

---

## About This Challenge

The goal of this challenge is to build a strong practical understanding of Terraform by learning and practicing something new every day for 31 days.

Each day contains:

* Concepts learned
* Hands-on practice
* Terraform configuration files
* Commands reference
* Screenshots & workflow diagrams
* Key takeaways
* Useful resources

The focus is on **learning by doing** rather than only reading documentation.
